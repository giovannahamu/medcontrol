## Problema Real

Idosos e pessoas com doenças crônicas frequentemente precisam tomar múltiplos medicamentos em horários diferentes ao longo do dia. Esquecer uma dose ou confundir remédios pode causar sérios riscos à saúde.

## Proposta da Solução

O **MedControl** é uma aplicação web simples e acessível que permite cadastrar medicamentos com horários e dosagens, consultar a lista a qualquer momento e receber alertas dos remédios a serem tomados.

A partir da **Etapa 3**, os dados são persistidos em um **banco de dados PostgreSQL na nuvem (Supabase)**, substituindo o arquivo JSON local.

## Banco de Dados — Supabase

### Como configurar o Supabase

1. Acesse [supabase.com](https://supabase.com) e crie uma conta gratuita
2. Crie um novo projeto
3. No **SQL Editor**, execute a seguinte query para criar a tabela:

```sql
create table medicamentos (
  id bigint generated by default as identity primary key,
  nome text not null,
  dose text not null,
  horarios text[] not null,
  created_at timestamptz default now()
);
```

4. Vá em **Project Settings → API** e copie:
   - `Project URL` → será sua `SUPABASE_URL`
   - `anon public key` → será sua `SUPABASE_KEY`

### Variáveis de Ambiente

Crie um arquivo `.env` na raiz (ou configure nas Settings do Streamlit Cloud / GitHub Secrets):

```env
SUPABASE_URL=https://SEU_PROJETO.supabase.co
SUPABASE_KEY=sua_anon_key_aqui
```

## Funcionalidades

- Cadastrar medicamento (nome, dose, horários)
- Listar todos os medicamentos cadastrados
- Remover medicamento por ID
- Buscar medicamento por nome (parcial, case-insensitive)
- Ver alertas: quais medicamentos devem ser tomados no momento atual (janela de ±10 min)
- **Persistência real no Supabase** (dados salvos na nuvem entre sessões)

## Como Rodar Localmente

**Pré-requisitos:** Python 3.9+ e uma conta no Supabase.

```bash
# 1. Clone o repositório
git clone https://github.com/giovannahamu/medcontrol.git
cd medcontrol

# 2. Crie e ative o ambiente virtual
python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate          # Windows

# 3. Instale as dependências
pip install -r requirements.txt

# 4. Configure as variáveis de ambiente
# Crie um arquivo .env com SUPABASE_URL e SUPABASE_KEY
# (veja seção "Banco de Dados" acima)

# 5. Execute a aplicação
streamlit run src/app.py
```
